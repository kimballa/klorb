
In the TUI, subagent sessions have an indicator at the bottom of the screen that says "Subagent is
still working..." when they are, in fact, working. This should do the same "animated highlight"
animation effect we do on the word "Running..." when a long-running tool call is running. 

That is, a highlight color should be patiently progressed left-to-right one letter at a time through
the indicator text so that the user knows that the program is not frozen.
